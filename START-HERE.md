## ⚡ Quick Deploy (40 minutes)

### Step 1: Create Accounts (5 min)
```
✅ GitHub: github.com/signup
✅ Vercel: vercel.com (use GitHub login)
✅ Render: render.com (use GitHub login)
✅ Firebase: console.firebase.google.com (use Google)
```

### Step 2: Firebase Setup (10 min)
```
1. Create project
2. Enable Firestore
3. Enable Authentication
4. Copy config values
```
📖 Detailed guide: `DEPLOYMENT-STEPS.md` (STEP 1)

### Step 3: Push to GitHub (2 min)
```bash
git init
git add .
git commit -m "Ready to deploy"
git remote add origin YOUR_REPO_URL
git push -u origin main
```

### Step 4: Deploy Frontend (5 min)
```
1. Go to vercel.com
2. Import your GitHub repo
3. Root directory: frontend
4. Add environment variables
5. Deploy!
```
📖 Detailed guide: `DEPLOYMENT-STEPS.md` (STEP 3)

### Step 5: Deploy Backend (10 min)
```
1. Go to render.com
2. New Web Service
3. Connect GitHub repo
4. Root directory: backend
5. Add environment variables
6. Deploy!
```
📖 Detailed guide: `DEPLOYMENT-STEPS.md` (STEP 4)

### Step 6: Connect & Test (5 min)
```
1. Update Vercel env with backend URL
2. Redeploy
3. Test your live site!
```
